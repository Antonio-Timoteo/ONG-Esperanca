# ONG Esperança - Aplicação Web SPA

Aplicação web desenvolvida com arquitetura Single Page Application (SPA), focada em acessibilidade (WCAG 2.1), responsividade e alto desempenho de carregamento.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Variáveis CSS, Flexbox, Design System)
- JavaScript ES6+ (Manipulação do DOM, LocalStorage)
- Vite (Bundler e Minificador)

## 🛠️ Como Executar
1. Instale as dependências: `npm install`
2. Inicie o servidor de desenvolvimento: `npm run dev`
3. Gere o build de produção: `npm run build`
